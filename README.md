# STICKBREAK

A portrait mobile stickman clicker game built with HTML Canvas and vanilla JavaScript.

## Play

Open `index.html` in a browser, or enable GitHub Pages under Settings → Pages → Deploy from a branch → `main` / root.

## Features

15 weapons with specified prices and damage; stickman animation and knockback; coins, shop and localStorage saves; KO/reset; settings for multiplier, HP, shake, and colors; synthesized hit sounds and supported vibration.

## Notes

Browser audio requires user interaction. Music is not yet implemented. This is an initial build and has not been tested on physical iPhone hardware.
